# BALA AI — शुरुआती Android प्रोजेक्ट

यह BALA AI का शुरुआती डेमो प्रोजेक्ट है। इसमें:
- हिंदी Speech Recognition (फोन की उपलब्ध सेवाओं पर निर्भर)
- Android Text-to-Speech
- YouTube, WhatsApp और Settings खोलने के उदाहरण
- एक साधारण Android स्क्रीन

## अभी क्या शामिल नहीं है
- इंटरनेट आधारित AI चैट/API
- तुम्हारी आवाज़ की क्लोनिंग
- बैकग्राउंड में हमेशा सुनना
- फोन कॉल अपने-आप उठाना या कॉल रिकॉर्ड करना

ये सुविधाएँ अलग-अलग चरणों में, अनुमति और सुरक्षा सीमाओं को ध्यान में रखकर जोड़नी होंगी। अपनी API key को सार्वजनिक ऐप कोड में न डालें।

## APK बनाने का आसान रास्ता
1. ZIP को ऐसे Android IDE/Gradle build environment में खोलें जो Android Gradle Plugin 8.7.3 और JDK 17 सपोर्ट करता हो।
2. Gradle sync करें।
3. `app` का debug APK build करें।
4. APK को अपने फोन पर इंस्टॉल करें और माइक्रोफ़ोन अनुमति दें।

केवल फोन से APK बनाना संभव हो सकता है, लेकिन IDE और फोन के अनुसार सेटअप बदलता है। यह ZIP स्रोत प्रोजेक्ट है, तैयार APK नहीं।
